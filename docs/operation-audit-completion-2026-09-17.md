## Additional defects fixed in this review

The five old ABS macro readers selected the first nearby number in HTML. Review against fresh official release tables found the WPI reader collecting **0.8% quarterly** while its intended measure was **3.2% annual** for June 2026. The NOM metric used a rounded annual number under an ambiguous quarterly label. Source links alone did not establish correct series meaning.

Collection now checks the exact publication title, dedicated reference-period field, unique table caption, named measure/adjustment column and exact current-period row. Missing, suppressed, duplicated, wrong-unit or changed-layout data is withheld and reported per source. It cannot borrow an older row or a number from prose. These are explicit **release-table contracts**, not a claimed SDMX API migration. Free official source pages remain the source; unrelated API probes are retained for future verification.
